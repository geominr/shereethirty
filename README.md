# Thirty in Lamu

Static invitation site. Copy, images, links, and the guest password live in `site-data.json`.

Files:
- `index.html` — the invitation page.
- `site-data.json` — copy, image paths, links, flight rows, and the guest password.
- `styles.css`, `script.js` — presentation and behavior.

Default guest password: `lamu30`

The password gate is lightweight front-end protection only. It keeps casual visitors out, but anyone who can read the files can bypass it.
